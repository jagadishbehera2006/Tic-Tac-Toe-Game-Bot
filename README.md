
# AI-Based Tic-Tac-Toe Game Bot

## Project Description

This project is an AI-based Tic-Tac-Toe game
developed using Python and Streamlit.

It supports two modes:

1. Human vs Human
2. Human vs AI

The AI opponent uses the Minimax Algorithm
to select the best possible move.

## Technologies Used

- Python
- Streamlit
- Minimax Algorithm
- CSS

## Installation

Install the required libraries:

py -m pip install -r requirements.txt

## Run Application

py -m streamlit run app.py

## Features

- Interactive 3x3 game board
- Intelligent AI opponent
- Human vs Human mode
- Winner detection
- Draw detection
- Scoreboard
- Restart game

## AI Algorithm

Minimax Algorithm is used for AI decision-making.

The algorithm evaluates possible moves and
selects the best move to maximize the AI's
chance of winning.
